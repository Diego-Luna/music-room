# Lexique (jargon d’équipe)

| Terme | Sens |
|---|---|
| **flaky** / **flake** | Test instable, parfois rouge sans vrai bug |
| **live test** | Parle à un vrai service (Nest `:3000`), pas un mock |
| **mock** / **stub** | Fausse dépendance |
| **E2E** | Parcours complet |
| **smoke** | Chemin critique, pas exhaustif |
| **LGTM** / **nit** / **blocker** | Review : OK / détail / bloque le merge |
| **regression** | Ça marchait, c’est cassé |
| **happy path** / **edge case** | Nominal / cas limite |
| **race** | Bug d’ordre / timing |
| **tech debt** / **YAGNI** / **DRY** | Dette / ne pas coder « au cas où » / pas de copie inutile |
| **green / red** | CI OK / KO |
| **seed** | Données de démo en base |
